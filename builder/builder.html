Cómo se usa

1) Completa la marca y el título.
2) Agrega capturas (botón "+ Captura") — puedes seleccionar varias a la vez.
3) En cada paso, arrastra sobre la imagen para dibujar el recuadro. Ajusta con los inputs numéricos (cx, cy, w, h) para precisión al pixel.
4) La Vista previa en vivo muestra exactamente cómo se verá el zoom en el tutorial final.
5) "Exportar config v2" genera el config.json para el build pipeline. "Exportar HTML" genera el tutorial listo para deploy.
6) "Guardar borrador" guarda el estado completo (con imágenes base64) para continuar después.
